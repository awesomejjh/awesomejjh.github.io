필담이(패키지 kr.sasoware.largetalk)는 사용자가 누른 말하기의 음성인식 결과와 직접 입력한 문장을 큰 글씨로 보여주는 앱입니다. 운영 주체는 개인 개발자 SASOWARE입니다. 문의 및 개인정보 관련 권리 행사는 sasosupport@gmail.com으로 요청할 수 있습니다.

마이크와 음성인식

사용자가 말하기를 시작하면 앱은 마이크 권한을 확인하고 Android SpeechRecognizer에 한국어 음성 인식을 요청합니다. 인식 결과는 화면에 큰 글씨로 표시됩니다. 마이크 권한을 거부하거나 철회해도 직접 입력과 수정 기능을 사용할 수 있습니다. 권한은 Android 설정에서 변경할 수 있습니다.

음성은 기기의 Android 음성인식 서비스가 처리합니다. 기기, 음성인식 서비스 및 설정에 따라 음성이 기기 안에서 처리되거나 네트워크를 통해 서비스 제공자에게 전달될 수 있습니다. 오프라인 처리를 보장하지 않습니다. 처리 위치, 보유 기간 및 삭제 방법은 이용 중인 음성인식 서비스의 설정과 개인정보처리방침을 확인해 주세요. 앱은 음성인식 요청을 전달하고 결과를 받습니다. 서비스가 별도로 보유하는 음성 데이터와 처리 이력은 SASOWARE가 조회하거나 삭제하지 않습니다.

대화 내용과 화면 설정

직접 입력하거나 인식한 문장은 화면에 표시됩니다. 화면 회전이나 Activity 복원 때 현재 표시 문장과 편집 중인 초안이 Android의 임시 화면 상태에 포함될 수 있습니다. 앱은 이를 파일이나 데이터베이스에 대화 기록으로 저장하지 않고, 대화 음성을 녹음 파일로 저장하지 않습니다. 개발자 서버로 보내지 않습니다.

글씨 크기와 화면 색상 설정은 기기의 앱 전용 저장 공간에 저장됩니다. 앱 데이터 삭제 또는 앱 삭제 시 설정도 삭제됩니다. SASOWARE는 기기의 문장이나 설정을 원격으로 조회하거나 복구할 수 없습니다.

계정, 광고 및 네트워크

필담이에는 회원가입, 로그인, 인앱결제, 광고·분석 SDK 또는 개발자 서버가 없습니다. 앱 자체에는 인터넷 권한이 없습니다. 다만 기기의 음성인식 서비스, 사용자가 선택해 보내는 지원 이메일, 이 방침 웹페이지를 제공하는 GitHub Pages는 각각 해당 서비스의 개인정보처리방침에 따라 정보를 처리할 수 있습니다.

문의 이메일과 보유·삭제

문의는 선택 사항입니다. SASOWARE는 문의 응대, 오류 재현 및 후속 확인을 위해 발신 이메일 주소, 문의 내용, 첨부파일 및 회신 내용을 전용 Gmail 계정에서 처리합니다.

문의 처리 목적을 달성하면 지체 없이 삭제합니다. 운영 목표는 문의 처리가 끝난 날부터 5일 이내에 삭제를 마치는 것입니다. 5일은 운영 목표이며 법정 기한을 뜻하지 않습니다. 전용 Gmail 계정에서 해당 문의의 주고받은 메일과 첨부파일을 삭제하고, Gmail 휴지통에서도 해당 항목을 영구 삭제합니다. Google 서비스 제공자 측 백업 등에서까지 삭제된다고 보장하지 않습니다.

실제로 적용되는 법령상 보존 의무가 확인되는 경우에만 그 의무를 이행하는 데 필요한 정보와 기간에 한해 예외적으로 보관합니다. 문의할 때에는 재현에 필요한 최소 정보만 보내 주세요. 실제 대화 전문, 음성 녹음, 비밀번호, 인증번호, 결제정보는 보내지 않아도 됩니다.

Google이 Gmail 제공자로서 별도로 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

개인정보 보호 권리

SASOWARE가 보유한 문의 정보에 대한 열람, 정정, 삭제 또는 처리정지를 sasosupport@gmail.com으로 요청할 수 있습니다. 가능하면 기존 문의에 사용한 주소에서 문의 날짜와 요청 범위를 알려 주세요. 필요한 최소 범위에서 본인 여부를 확인한 뒤 처리 결과를 안내합니다. 음성인식 서비스가 별도로 처리하는 정보는 해당 서비스 제공자의 권리 행사 절차를 이용해 주세요.

시행일과 변경

시행일은 이 방침을 실제 공개하도록 승인한 날로 입력합니다. 처리 내용이나 이용자 권리에 관한 내용이 바뀌면 변경 내용과 시행일을 안내합니다.

개인정보처리방침 웹페이지의 호스팅

공개된 이 방침 웹페이지는 GitHub Pages에서 호스팅됩니다. GitHub 공식 문서는 GitHub Pages 사이트를 방문할 때 로그인 여부와 관계없이 방문자의 IP 주소를 보안 목적으로 기록하고 보관한다고 안내합니다. GitHub의 개인정보 처리에는 GitHub 개인정보처리방침이 적용됩니다. 방문 데이터가 실제로 처리되는 국가나 구체적인 전송 경로는 이 문서에서 특정하지 않습니다.

이 방침 페이지에는 SASOWARE가 추가한 광고·분석 스크립트나 입력 양식이 없습니다. 다만 호스팅 제공자의 처리와 이 페이지에서 연결한 외부 사이트에는 각 제공자의 방침이 적용됩니다. GitHub Pages 방문 데이터의 처리·보유·삭제 문의는 GitHub에, SASOWARE가 보유한 지원 이메일 문의 정보는 SASOWARE에 요청해 주세요.
