# 필담이 개인정보처리방침 — 공개 Draft PR 검토본

**검토 상태:** 공개 저장소에서 본문을 검토하기 위한 파일입니다. **공식 사이트에 게시된 정책이 아닙니다.**

- 검토 본문: [privacy-policy-draft.html](privacy-policy-draft.html)
- 제안된 향후 정책 경로: `/pildami/privacy/` (**현재 실제 운영 주소 아님**)
- 제품: 필담이 · Android 패키지 `kr.sasoware.largetalk`
- 시행일: 아직 승인되지 않았으며, 실제 게시 승인일에 결정합니다. 검토본의 날짜 자리표시자는 그대로 둡니다.
- 공개 Draft PR이므로 본문은 GitHub에서 누구나 읽을 수 있습니다. 단, 원고를 검토할 수 있다는 뜻이지 사이트 배포·법적 최종 승인을 의미하지 않습니다.

## 배포 차단 범위

이 변경은 `review-only/` 디렉터리의 파일 2개만 추가합니다.

- 기존 `template/`(DANBI와 SASOWARE 사이트 템플릿), `scripts/build.py`, `scripts/validate.py`, `.github/workflows/publish.yml` 등 운영·배포 대상은 변경하지 않습니다.
- 현재 사이트 빌드는 `template/`만 `_site/`로 복사하므로, **검토 파일은 사이트 빌드·배포물에 포함되지 않습니다**.
- PR은 Draft로 유지하고 병합·배포·Pages 설정/승인 값 변경을 하지 않습니다.

## 정식 게시 전에 별도로 필요한 결정

1. Gmail 문의 보유·삭제 절차를 실제로 수행할 수 있는지 확인하고, 원고의 운영 목표(문의 처리 완료 후 5일 이내 삭제) 및 고지 내용을 최종 검토합니다.
2. DANBI의 기존 Pages 콘텐츠를 보존하는 **필담이 단독 게시 경로**를 설계·검증합니다. 기존 DANBI 포함 전체 사이트 게시 워크플로를 이 검토 승인만으로 실행하지 않습니다.
3. 실제 공개 승인을 받은 날짜를 한국 기준 시행일로 입력하고, 검토 배너·검색 차단 표시·자리표시자를 정식 게시본에서만 제거합니다.
4. HTTPS 정책 URL의 응답, 정책 전문, 앱 내 정책 내용 일치 여부를 확인합니다.
5. Google Play Console의 기존 버전코드·업로드 인증서를 확인한 다음 승인된 별도 절차로 배포 판단합니다.

**현재 사용자의 승인 범위:** 정책 본문을 볼 수 있는 공개 GitHub Draft PR 생성까지. 사이트 게시, Play 업로드, 프로덕션 출시, 현재 DANBI 페이지의 변경은 승인되지 않았습니다.
